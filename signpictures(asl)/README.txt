📸 SIGN LANGUAGE PICTURES
========================

How to add sign language pictures:

1. Download or create sign language images for each letter/word
2. Name them exactly as: A.jpg, B.jpg, C.jpg, etc.
3. Put them in this folder

Supported formats:
- .jpg
- .png
- .jpeg
- .gif

File naming:
- Letter: A.jpg, B.jpg, Z.jpg
- Words: HELLO.jpg, THANK.jpg, LOVE.jpg
- Case insensitive (a.jpg = A.jpg)

Example:
signpictures/
├── A.jpg
├── B.jpg
├── C.jpg
├── HELLO.jpg
└── THANK.jpg

When user says "HELLO":
- App converts it to letters: H, E, L, L, O
- Displays corresponding images from this folder
- User performs those signs in front of camera

If image not found, letter will be shown instead.
